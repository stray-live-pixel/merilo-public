# Сценарии использования merilo

Начни с задачи, которую хочешь решить.

- [Направить обращение, разобрать отзыв или письмо](choice.md) — выбор одной категории.
- [Заметить просьбу о возврате, неоплаченный счёт или противоречие](noul.md) — проверка утверждения.
- [Оценить инструкцию, серьёзность дефекта или ответ поддержки](score.md) — оценка по шкале.
- [Проверить объявление или код сразу по нескольким аспектам](configurations.md) — готовый набор вопросов.
- [Сравнить версии и выделить спорный случай для ручной проверки](results.md) — применение результатов.

Каждый сценарий содержит задачу, запрос, иллюстративный результат и разбор дальнейшего решения.

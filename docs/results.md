# Результаты: превратить оценки в рабочее решение

Примеры результатов ниже иллюстративные: показаны только поля, необходимые для разбора, а не реальные замеры.

## Выбрать более понятный текст уведомления

### Задача пользователя

У продуктовой команды две версии уведомления об ошибке оплаты. Нужно понять, какая лучше объясняет следующий шаг. Обе версии проверяются одним и тем же вопросом.

### Запрос

```bash
args=(
  -api-key "$OPENROUTER_API_KEY"
  -model deepseek/deepseek-v4.1-flash
  -effort xhigh
  -type score
  -repeats 5  # Для каждой версии собираем несколько оценок.
  -question 'Понятно ли клиенту, что сделать после ошибки оплаты?'
  -levels 'Следующий шаг непонятен|Следующий шаг понятен'
)

# Первая версия сообщает о проблеме.
merilo "${args[@]}" -context 'Ошибка 402. Повторите операцию.'

# Вторая версия предлагает конкретные действия.
merilo "${args[@]}" -context 'Оплата не прошла. Проверьте баланс или выберите другую карту. Если деньги уже списались, не платите повторно — напишите в поддержку.'
```

### Пример результата

```json
{
  "version_a": {
    "score": 0.35
  },
  "version_b": {
    "score": 0.9
  }
  ...
}
```

### Как использовать результат

Здесь для наглядности сведены фрагменты двух отдельных ответов CLI; полей version_a/version_b сам инструмент не добавляет. Вторая версия получила более высокую оценку по выбранному критерию и лучше подходит для следующего пользовательского теста. До публикации команда проверит, верны ли рекомендации для реального платёжного процесса.

## Решить, стоит ли проверять спорный материал вручную

### Задача пользователя

Ты проверяешь, содержит ли рекламный текст обещание гарантированного результата. В спорных формулировках важен не только итог, но и согласованность отдельных оценок.

### Запрос

```bash
args=(
  -api-key "$OPENROUTER_API_KEY"
  -model deepseek/deepseek-v4.1-flash
  -effort xhigh
  -type noul
  -repeats 5  # Несколько оценок одного материала.
  -question 'Обещает ли текст гарантированный результат каждому покупателю, а не описывает возможную пользу?'  # Что важно для этой задачи.
)

# Материал, который требуется оценить.
merilo "${args[@]}" -context - <<'TEXT'
Наш курс поможет вам уверенно пройти собеседование. С нами новая работа уже близко.
TEXT
```

### Пример результата

```json
{
  "noul": 0.5,
  "aggregation": "median",
  "samples": [
    {
      "result": {
        "noul": 0.2
      }
    },
    {
      "result": {
        "noul": 0.8
      }
    },
    {
      "result": {
        "noul": 0.5
      }
    },
    {
      "result": {
        "noul": 0.7
      }
    },
    {
      "result": {
        "noul": 0.3
      }
    }
  ]
  ...
}
```

### Как использовать результат

Ответы расходятся, а медиана находится в середине шкалы. Редактору стоит прочитать формулировку и уточнить обещание, прежде чем делать вывод по одному числу. Это пример того, как повторные оценки помогают выделить спорный случай для ручного разбора, а не скрыть его за итоговым баллом.

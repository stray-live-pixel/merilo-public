# Локальный playground

## Запуск

```bash
merilo -ui
```

Открой напечатанный адрес: по умолчанию http://127.0.0.1:8080. Остановка — Ctrl+C в терминале. Если порт занят, укажи `-port 8081`.

Формы доступны без ключа. При запуске проверки OpenRouter без ключа открывается модалка ввода; её можно закрыть и выбрать Codex. Можно передать ключ OpenRouter при запуске:

```bash
merilo -ui -api-key "$OPENROUTER_API_KEY"
```

Ключ из CLI не отправляется в HTML. Кнопка «Сменить API-ключ» снова перекрывает интерфейс модалкой, сохраняя формы и результаты. Новый ключ переопределяет серверный. Ввод и смену ключа можно отменить. Наличие ключа проверяется локально, его действительность — при запросе OpenRouter. Приложение не сохраняет ключ, черновики или историю на диск и не использует localStorage. Черновики разных вкладок живут в памяти страницы; после перезагрузки они сбрасываются.

## От задачи к результату

1. Выбери вкладку **Choice**, **Noul**, **Score** или **Конфигурация**.
2. Примени шаблон этой вкладки либо очисти форму и задай свою проверку.
3. Заполни вопрос и контекст. В Choice добавь категории; в Score — упорядоченные уровни. Кнопки рядом с вариантами добавляют, удаляют и меняют порядок. У Score виден диапазон итогового балла.
4. При необходимости раскрой **Технические настройки**: провайдер, модель, рассуждения, повторы, параллелизм. Ключ меняется отдельной кнопкой в шапке. Шаблон подставляет настройки своего сценария, их можно изменить.
5. Нажми **Запустить проверку** в закреплённой правой колонке над результатом. Справа появятся оценки, расход и полный JSON с отдельными повторами и ошибками. Копирование JSON доступно после получения результата.

У каждой вкладки свои черновик, шаблоны и последний результат. Переключение вкладок не теряет введённый текст. Если изменить форму после запуска, прежний результат помечается как относящийся к другим параметрам.

## Несколько проверок

Во вкладке **Конфигурация** доступны готовые наборы качества кода и смешанных проверок. Они используют те же JSON-файлы, что и CLI. Вставь анализируемый код в общий контекст.

Каждая проверка — отдельная карточка: id, категория, режим, вопрос и список вариантов или уровней. Карточки можно добавлять и удалять. В блоке «Настройки этой проверки» задаются исключения из общих provider/model/effort/repeats/concurrency. Общий параллелизм остаётся потолком всего запуска.

В разделе «Импорт и редактирование JSON» можно вставить собственный конфиг и применить его к форме. Данные `__external__` сохраняются и возвращаются в результате; редактировать их можно через JSON. Неизвестные настройки отвергаются сервером до платного запроса.

## Шаблоны и выполнение

В UI доступны 15 шаблонов по примерам из документации, включая 2–4 уровня Score, пять повторов и 100 параллельных оценок. Шаблоны для анализа файлов используют небольшой пример кода либо предлагают вставить свой контекст. Применение шаблона само по себе ничего не отправляет.

Одновременно интерфейс допускает один запуск, внутри которого действует настроенный параллелизм проверок. Повторы, медианы, обработка некорректных ответов и учёт расхода совпадают с CLI. Частичные результаты остаются доступны при ошибках. Закрытие вкладки не отменяет уже начатые запросы; для остановки процесса используй Ctrl+C.

Сервер слушает только 127.0.0.1. Внешние сайты не могут запускать запросы через него: проверяются Host, Origin и сессионный токен. Контекст отправляется выбранному провайдеру: OpenRouter оплачивается по тарифу модели, Codex расходует лимиты подписки.

## Экспорт текущей формы

В правой колонке есть вкладки «Результат», «JSON-конфиг» и «Команда». Экспорт обновляется при изменении формы без запуска LLM. У каждой вкладки экспорта своя кнопка копирования.

JSON содержит конфигурацию проверок, но не контекст и не ключ: это обычный конфиг CLI. Команда включает конфиг через process substitution и контекст через -context; её можно вставить в Bash или Zsh с установленным `merilo` в PATH. Для конфигураций с OpenRouter в ней стоит `-api-key "$OPENROUTER_API_KEY"`, а не реальный ключ из модалки или сервера. Переменную нужно установить самостоятельно. Текст контекста экранируется как данные, включая кавычки, переносы и shell-символы.

Экспорт допускает незаполненный черновик — перед выполнением проверь необходимые поля. Ни экспорт, ни копирование не вызывают модель.

## Тема и компоновка

Светлая и тёмная темы выбираются автоматически по `prefers-color-scheme`, включая изменение настройки системы при открытой странице. Отдельного переключателя нет. Компактные отступы, контрастные поля и состояния hover/focus/active рассчитаны на работу с панелью тестирования. Правая колонка с запуском закреплена на широком экране; на узком размещается перед формой.

Стоимость в UI показана в USD и рублях по фиксированному курсу $1 = 100 ₽. Данные API и экспортируемый JSON остаются в USD; рубли — только отображение.
